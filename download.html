RAGTerminal is a macOS workbench for organizing knowledge and building reusable RAG workflows. This page separates the desktop app from the assets shared by the Community catalog so you know exactly what you are downloading.

01 / DESKTOP APP

macOS installer

A signed, public desktop installer has not been published on the Hub yet. We will link directly to the official app package here once a release is available.

Public installer not yet available
02 / BUILD FROM SOURCE

Build on your Mac

If you already have the RAG Terminal source project on your Mac, build the app from the project root with its build script.

./macos/build_app.sh

A macOS development toolchain and the app source tree are required.

03 / COMMUNITY ASSETS

Download reusable packs

Discover Knowledge, Flows, Blocks, Scripts and Plays published by the community. These packages are content for RAGTerminal—not the desktop app installer.
